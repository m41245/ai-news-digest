# Prompt 01 — AI News Digest Project Blueprint

You are acting as the Lead Software Architect for this project.

Before writing any code, design the architecture for a production-ready AI News Digest platform.

The application will:

- Collect AI news from trusted RSS feeds and websites.
- Remove duplicate articles.
- Use an LLM to summarize articles.
- Categorize articles.
- Store articles in a database.
- Generate daily digests.
- Expose REST APIs.
- Be fully Dockerized.
- Be production-ready.
- Be easy to extend.

Design the architecture only.

Do NOT generate implementation code.

Instead, provide:

1. Folder structure
2. Responsibilities of every folder
3. Responsibilities of every package
4. Naming conventions
5. Error-handling strategy
6. Logging strategy
7. Configuration strategy
8. Dependency injection strategy
9. Testing strategy
10. Future scalability considerations

The goal is to establish engineering standards before implementation.
